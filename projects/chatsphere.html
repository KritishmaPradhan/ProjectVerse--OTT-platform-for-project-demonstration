🎬 Overview

ChatSphere is a real-time messaging, audio calling, and collaboration platform. It offers sleek custom-themed chat rooms where users can share code snippets with syntax highlighting, collaborate on whiteboards, and send media in lightning-fast channels using WebSockets.

⚠️ Problem Statement

Most casual messaging web apps lack tools tailored for developers, such as seamless multi-language code editors, real-time board collaboration, and custom ambient lighting corresponding to room vibes or focus states.

✨ Key Features

  • Instant WebSocket Messaging with Socket.io
  • Collaborative Code Editor with Live Syntax Highlighting
  • Interactive SVG Sketchpad & Whiteboard
  • Dynamic Ambient Interface & Soundscapes
  • Encrypted Direct & Channel Messaging

🔥 Challenges Faced

Managing concurrent cursor positions and text edits in the collaborative code sharing editor without race conditions or character overriding was extremely challenging. Frequent desyncs occurred during high latency connections.

🧠 What I learned

I implemented Operational Transformation (OT) concepts and integrated conflict-free replicated data types (CRDTs). I also refined React's state management render cycles to handle heavy WebSocket stream loads.
