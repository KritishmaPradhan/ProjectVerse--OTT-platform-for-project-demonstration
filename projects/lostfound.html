Lost & Found

A smart, localized portal to report, track, and recover items.

▶
WATCH CINEMATIC DEMONSTRATION Voice-Over Narration Included

🎬 Overview

Lost & Found is a community-driven locator portal tailored for college campuses. It allows users to report lost or found items, classify them via auto-tagging, set security-conscious blur thresholds for claim validation, and securely negotiate drop-off locations with unified local profiles.

⚠️ Problem Statement

Lost-and-found systems in communities are often fragmented, relying on physical bulletin boards, Facebook groups, or mass emails. This results in poor recovery rates, identity leak issues on public forums, and lack of verified claims, making finding items extremely stressful.

✨ Key Features

  • AI Tagging & Smart Categorization
  • Secure Claim Validation & Image Blur Mechanism
  • Dev Tunnel Integration for Mobile Access
  • Real-time Matches Notification via Push
  • Privacy-first User Intercom System

🔥 Challenges Faced

Securing cross-port CORS and CSRF authentication under dev-tunnels for remote mobile checking while protecting sensitive user profiles from malicious claims was a complex network blocker. Resolving Vite dev configuration proxies took intensive debugging iteration.

🧠 What I learned

I configured robust Vite proxies, Laravel Sanctum token exemptions, and implemented detailed cryptographic verification tags for user claim verification. I also refined cross-device responsive layout standards to solve fluid dimension issues.
